🍕 RecipeCart – React Shopping Cart

A responsive shopping cart application built using React.

🚀 Live Demo

"Visit RecipeCart" (https://react-recipe-cart.vercel.app)

✨ Features

- Add products to cart
- Increase and decrease product quantity
- Remove individual items
- Clear entire cart
- Automatically calculate total price
- Display total cart items
- Empty cart message

🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

💻 Run Locally

1. Clone the repository:

git clone (https://github.com/Somoo-raj/ReactRecipeCart.git)

2. Navigate to the project folder:

cd react-recipe-cart-app

3. Install dependencies:

npm install

4. Start the development server:

npm run dev

🌐 Deployment

Deployed using Vercel.
